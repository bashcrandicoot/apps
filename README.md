# bashframes apps

Catalog of bashframes apps. The site is `index.html` and `assets/`.

It is live at <https://bashfra.me/apps/> and <https://bashcrandicoot.github.io/apps/>. <https://bashfra.me/apps/> is an hourly synced copy in the links repo.

## Apps

- **Lodge.** Mac app, $10 once with a 3-day free trial. Direct download: <https://dl.bashfra.me/lodge/Lodge-1.0.dmg>. Site: <https://bashfra.me/lodge/>.
- **Loadout.** Coming soon.
- **PilotLight.** See when your Mac is busy with a bot. Free and open source.
- **Crate.** Coming soon.

## Edit

Edit `index.html` and `assets/` in this repo, then merge to `main`. GitHub Pages publishes <https://bashcrandicoot.github.io/apps/>. <https://bashfra.me/apps/> updates from the hourly sync in the links repo.
